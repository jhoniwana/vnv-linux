What it does for you

> Step 1 · SURVEYDetects your distro (Debian, Ubuntu, Arch, Fedora, openSUSE…) and installs Python, Camoufox and the system libraries. With retries and diagnostics.
> Step 2 · STEAMDiagnoses Steam, Fallout New Vegas and the Proton prefix. Sets up the environment so Mod Organizer 2 runs inside the game's prefix.
> Step 3 · NEXUSAutomatic Nexus Mods login (passes the Turnstile captcha on its own) and saves the session for free downloads.
> Step 4 · SUPPLYDownloads the 55 Core mods with integrity verification, retries and power-outage continuity (persistent state).
> Step 5 · DEPLOYCreates the MO2 instance, imports the 55 mods in canonical order, applies the native root mods (xNVSE, 4GB, ESM Fixes) with post-step verification.
> LAUNCHLaunches the game from MO2 with all mods mounted via VFS. No Wine for the root mods: everything runs natively on Linux.

Getting started

Requirements: Steam with Fallout New Vegas (run once with Proton), a free Nexus Mods account and ~4 GB of space.

1Clone and start 
git clone https://github.com/jhoniwana/vnv-linux
cd vnv-linux
./vnv.sh ui

A browser opens with the Pip-Boy wizard — each step with its own button and live progress.

2Terminal mode (optional) 
./vnv.sh setup        # environment (multi-distro, auto-installs deps)
./vnv.sh login        # Nexus cookies (passes Turnstile)
./vnv.sh download     # downloads the 55 mods (1.1 GB, with retries)
./vnv.sh install      # MO2 + mods + root mods + INIs + LOOT
./vnv.sh salud        # 12 health checks (exit 0 = healthy)
./vnv.sh run          # launches the game
3Play

New game -> check Stewie Tweaks in Settings = mods loaded. Sprint and QOL from MCM (JAM).

The engineering behind it

> Nexus loginCamoufox (anti-detection Firefox) passes Turnstile headless. The real cookie is nexusmods_session (+ cf_clearance), saved with 600 permissions.
> Free downloadsEndpoint /Download/?id=…&game_id=130 works without Premium; the button lives in a web component's shadow DOM — solved by inspecting Nexus's JS bundle.
> BSA analyzedThe real header format (xEdit wbBSA.pas): compression = bit30 XOR (flags & 0x04). Verdict: the decompressor is a no-op on the current depot.
> ESM FixesThe .mpi wraps the VCDIFF patches in LZ4 frames; bit-exact validation against the official installer via Proton (identical SHA1).
> ContinuityDownloads survive power outages (persistent state) — proven with 2 real interruptions.
> Cross-distroVerified on Ubuntu 24.04, Arch Linux and EndeavourOS (docker + real): fresh setup, clean fallbacks, 12/12 health.

FAQ

Are the mods in the repo?

No. The repo only downloads the 55 mods with YOUR Nexus session (free). It redistributes nothing copyrighted.

Do I need Wine?

Only for MO2 (it runs inside the Proton prefix). The root mods (NVSE, 4GB, ESM Fixes) are native — no Wine.

Steam verified the game and something broke

That's expected: verify reverts the root mods and INIs. Just re-run ./vnv.sh install (idempotent) and you're done.

What about the guide's BSA Decompressor?

You don't need it. The 11 BSAs it touches already ship uncompressed on the current depot (2026). Installing the mod changes nothing.

Old saves?

Saves from another installation are not compatible (formids renumbered by the ESM Fixes). Start a new game.
